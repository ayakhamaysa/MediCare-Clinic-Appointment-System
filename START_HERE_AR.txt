قالب العيادة الجاهز للبيع
========================

لكل دكتور جديد:

1) انسخي مجلد المشروع كاملًا وغيّري اسم المجلد.

2) عدّلي clinic.config.ts فقط لبيانات العيادة والطبيب والدخول.

3) من Cloudflare أنشئي D1 Database جديدة، ثم عدّلي database.config.json:
   workerName   = اسم إنجليزي مختلف للموقع، مثل clinic-noor
   databaseName = اسم قاعدة البيانات كما كتبته في Cloudflare
   databaseId   = الرقم الطويل الذي أعطاك إياه Cloudflare

4) افتحي Terminal داخل المجلد وشغّلي:
   npm install
   npx wrangler login
   npm run deploy

شغّلي كل أمر وحده وانتظري حتى ينتهي. تسجيل الدخول مطلوب مرة واحدة فقط على جهازك.
بعد ذلك، للنسخ الجديدة يكفي عادةً: npm install ثم npm run deploy.

انتهى. سيظهر رابط الموقع، والجداول تُنشأ تلقائيًا عند فتحه أول مرة.

مهم: لكل دكتور workerName مختلف وقاعدة بيانات جديدة باسم ورقم مختلفين.
لا تعدّلي wrangler.jsonc أو أي ملف داخل dist؛ أمر النشر ينشئهما ويصححهما تلقائيًا.
